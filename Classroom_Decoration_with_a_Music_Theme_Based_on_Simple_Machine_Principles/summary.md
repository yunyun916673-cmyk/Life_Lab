# Classroom_Decoration_with_a_Music_Theme_Based_on_Simple_Machine_Principles

## 背景與動機

進入高中後，我成為班上的學藝股長，因此需要負責教室布置比賽的相關事項。由於班上另一位學藝股長十分擅長音樂，在與他討論後，我們決定將音樂元素融入這次的教室布置之中。

在思考如何呈現音樂主題時，我希望這次的布置不只是將音樂相關的圖案與元素作為裝飾，而是能夠真正將自己過去學習與實作中累積的知識運用其中。過去在物理課程的學習過程中，我逐漸對「如何利用原理讓一個想法實際運作」產生興趣。因此，我希望藉由這次教室布置的機會，將原本在學習中接觸到的知識轉化為實際的作品，嘗試親手製作一些與音樂相關的簡單機械。

同時，我也希望這些作品不只是完成布置本身，而能成為讓同學理解科學原理的媒介。透過實際展示磁力、機械結構與音樂裝置的運作方式，讓大家看見原本抽象的原理如何被應用在生活中。對我而言，這次教室布置不只是一次班級活動，也是一次將所學知識實際應用、測試想法並與他人分享的機會。

## 設計規劃

本次教室布置預計以「音樂與物理原理」為核心，設計四項主要作品。除了將音樂元素融入教室布置之外，也希望讓同學能夠實際操作裝置，從觀察聲音與機械運動的現象，進一步了解其中所涉及的物理原理。

1. 巨型木琴

第一項主要作品為巨型木琴，由六塊長度不同的木板組成，並按照長度由長至短排列。其中最長的木板約為 90 公分，最短的木板約為 15 公分。

木板會固定於教室牆面上，並使用氣泡膠以及其他輔助黏著材料進行固定。設計上不讓木板與牆面完全貼合，而是在木板與牆面之間保留一定的空間，使木板受到敲擊時能夠自由振動，希望藉此讓聲音更加明亮、清脆。

木板旁會懸掛一個木槌，讓同學可以自行拿取並敲擊不同長度的木板。透過實際比較六塊木板所產生的聲音，讓同學觀察木板長度不同是否會造成聲音頻率與音高的差異。

2. 磁力敲擊鐘

第二項主要作品為磁力敲擊鐘，利用磁鐵「同極相斥、異極相吸」的特性，設計一個可以讓同學操作的互動式敲擊裝置。

裝置內部設計一個按鈕結構。當按鈕尚未被按下時，特定位置會由 S 極磁鐵位於作用線上；當同學按下按鈕後，原本的 S 極磁鐵會向下移動，使另一個 N 極磁鐵進入作用位置。

在作用線的前方設置一個小槌子，槌子後方固定一顆 N 極朝外的磁鐵。因此，當按鈕被按下時，兩個 N 極互相排斥，使小槌子向前擺動並敲擊前方的金屬管；當按鈕放開並恢復原位後，磁鐵的作用力改變，使小槌子被 S 極磁鐵吸回原本的位置。

前方預計懸掛三根粗細不同的金屬管，並由粗至細排列。三組相同的敲擊機構會設置於同一個平台上，使同學可以分別操作不同的金屬管，觀察金屬管粗細不同時，所產生的聲音是否有所差異。

3. 音樂盒機芯原理互動裝置

第三項主要作品為音樂盒機芯原理互動裝置，主要目的是讓同學能夠直接觀察音樂盒機芯的運作方式。

裝置以三角柱形木箱作為外部結構，內部設置一個架子，架子上放置音樂盒機芯。機芯上的擺臂會透過一根木棒連接至木箱上方，因此同學可以透過上下來回移動木棒，使箱內的擺臂跟著運動，進而帶動音樂盒機芯發出聲音。

整個裝置會放置於教室角落的兩面牆壁所形成的垂直夾角中。為了讓同學能夠直接觀察內部機械結構，面向同學的一側以及木箱上方會使用硬質透明壓克力板取代部分木板，使內部機構能夠清楚呈現。

此外，木箱正前方會設置聲音出口，並在出口上方設置一片可以上下移動的壓克力板。同學可以透過移動壓克力板改變聲音出口的大小，觀察開口大小改變後，聲音的傳播與聽覺效果是否產生變化。

4. 樂器發聲原理說明

第四項作品以圖像與文字作為主要呈現方式，介紹鋼琴與吉他的發聲原理。

內容將透過樂器的結構圖與簡單文字說明，讓同學了解琴弦振動、共鳴以及聲音傳播等相關概念，並將實際樂器的構造與前述互動裝置所呈現的物理現象互相連結。

同時，在查詢與整理鋼琴及吉他發聲原理的過程中，也能進一步了解過去較少接觸的聲學知識，將資料蒐集本身也作為本次專案學習的一部分。
